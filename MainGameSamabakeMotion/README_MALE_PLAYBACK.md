# 男性の再生開始と状態同期

v0.4.1は人物のAnimator有効化とAlwaysAnimate設定を再生中だけ適用し、男性にも本体の状態切替イベントを明示転送する；停止・体位切替・適用失敗時は元の有効状態とカリング設定を復元する。

既存のv0.3立ちキスzipmodは追加カタログなしでも利用できる；`Test-Helper.ps1`と`Install-Helper.ps1 -ExpectedInstalledHash <調査時のDLLハッシュ>`でzipmodを変更せず補助DLLだけ検査・更新できる。

元の男性クリップに動きがあることは保存済みメッシュ検査から確認したが、今回の男性停止が再生無効・カリング・状態同期のどれに当たるかは実機の診断結果がなく未確定；検証用スタブの成功をゲーム内の動作確認として扱わない。

診断の有効無効は既存の`Diagnostics/Enabled`に従い、今回設定は変更しない；男性の状態切替と別体位への復帰をユーザーが実機で再確認する。
