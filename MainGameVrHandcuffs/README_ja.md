# 手錠A・B（MainGameVrHandcuffs）

通常H／公式VR用。canon_gateの許可を受けたHで、PlaybackBarの「手錠」から呼び出す。
初期表示・H開始時の自動生成はしない。モデルは handcuffs_pair_v14 の実メッシュをDLLへ埋め込んでいる。

## 操作

- PlaybackBar左クリック：視点前へ呼び出し → ギズモ表示を交互に実行。
- PlaybackBar右クリック：削除し、借りていた手首IKを元に戻す。
- AかBの近くでグリップを押して掴む。今回は片側ずつ。別の手からの押下で横取りしない。
- 掴んでいる側の輪の中心が女性の手首から5cm以内にあるとき、同じ手のトリガーで装着する。
- 同じ女性の左右の手首へ1つずつ装着できる。装着済み側への再トリガーや同じ手首への重複装着はしない。
- 装着成功時だけ、その側の手錠から残響付きの金属音を一度鳴らす（0.86秒、DLL埋め込み）。削除・終了では音声も停止・破棄する。
- 装着済みの手錠を掴んだまま同じ手のBを押すと、その側だけ装着を解除し、金属音を一度鳴らす。手首IKを元に戻し、手錠は掴んだまま残す。反対側の装着は維持する。未装着側や別の手のBでは解除しない。
- 解除入力は専用の `/actions/handcuffs/in/b`。Touch右B・左Yを使用し、A/Xやスティック押し込みと共用しない。入力manifestとcontroller bindingも配置する。
- 装着位置・角度は手首ボーンのローカル座標で完全固定。位置は左 `(0.008, 0.014, 0)` m、右 `(-0.008, 0.014, 0)` m。左右とA/Bの4組の固定回転を使用し、錠前を手のひら側（ローカル-Y）へ向ける。
- 前腕・指・反対側の手首の位置や、掴んだ角度から装着姿勢を計算しない。手首のワールド位置・回転に固定値を変換するだけで、装着するたびに同じ相対姿勢になる。
- 鎖は3コマ、取付環間の最大到達距離は5cm。鎖が張った分だけ反対側の手錠を直接移動する。たるんでいる間は反対側を動かさない。
- グリップを離すと両方の手錠と鎖がその場に固定される。装着した手首は位置・回転IK100％を維持する。
- 手錠・鎖にRigidbody、Joint、AimConstraintを生成しない。慣性、揺れ、ダンピング、物理補正、補間、追従遅延を使用しない。
- 装着済みのままA・Bを掴み直せる。鎖が張ると反対側の手首も引く。
- 呼び戻しは既存の装着を解除してから視点前へ置き直す。女性を視点前へ瞬間移動させない。

## IKと終了処理

MainGirlHipHijackの `TryGetRuntimeWrist` / `TryBindRuntimeWrist` で、一時的な所有者付き手首IKを取得する。
装着中は手錠の子の目標から手首を動かす。手錠自体を手首ボーンの子にはしない。
VR手首掴みでIK保持した手首にも装着できる。手首のグリップを離してから装着し、装着後は手錠を掴んで動かす。通常の手首掴み・BによるIK解除は装着中の手首を対象にしない。
装着済みの手錠を掴んだ状態で、同じコントローラーの物理A（Touch左手はX）を保持すると、その手首を支点に肘IKの目標方向を調整できる。Aまたはグリップ解放で肘の目標位置を保持する。延長距離はHipHijackの「肘IK延長(cm)」を共用する。
設定ファイルは変更せず、元の操作点・追従・ターゲット・ウェイトを保持し、解除時に復元する。
所有中の手首に対する既存の外部設定APIは失敗を返す。ポーズ遷移中・体位変更処理中は装着を拒否し、半端な装着を残さない。
削除、無効化、H終了では保持・入力購読・一時IK・モデル・Mesh／Materialを解放する。
フォーカス・トラッキング喪失では手を離した場合と同じく空間固定する。
VRのフォーカスはSteamVRの通知で判定し、デスクトップのゲームウィンドウのフォーカスをVRの掴み・装着条件にしない。

手の移動通知や独自Update／LateUpdate／FixedUpdateは追加していない。
掴んでいる間だけ、既存のヒップハイジャックのIK評価に距離制約の処理を接続する。
掴んだ側は親子付けで直接追従し、反対側は最大距離を超えた分のみ移動する。
鎖3コマは両端から幾何的に配置し、速度・経過時間・重力・反動を持たせない。
解放時は最後の手の位置を一度反映して評価の接続を外し、全パーツのワールド姿勢を保持する。
肘・肩・腰の追加計算、鍵による取り外し、両手同時保持、装着状態の保存は対象外。

## ビルドと配置対象

1. MainGirlHipHijackをReleaseでビルド。
2. MainGameVrHandcuffsとMainGameBlankMapAddをReleaseでビルド。
3. 配置が指示された場合だけ、ゲーム終了後に各プロジェクト自身の `bin/Release/net472` のDLLを、それぞれ正規プラグインフォルダへ配置する。

更新が必要なDLLは MainGirlHipHijack.dll / MainGameVrHandcuffs.dll / MainGameBlankMapAdd.dll。
手錠用メッシュは埋め込み済みで、Blenderや外部モデルローダーは不要。
装着音の原録音は jtnewlin13「Various Handcuff Sounds」（https://freesound.org/people/jtnewlin13/sounds/349864/ 、CC0 1.0）。切り出し・低音強調・残響を加工している。

## 検証

`Tests/Interaction/Interaction.Tests.csproj` は製品のVR入力・共有操作権・IK一時接続・固定処理・距離制約を直接リンクする境界テスト。
左右コントローラー×A/Bの装着順、掴み直し、二重装着拒否、失敗時の巻き戻し、復元、埋め込みメッシュを検査する。
Unity／VRの境界には代替を使用するため、キャラの描画・VRの掴み心地はゲーム内未確認。
ゲームの起動・操作は行わず、ユーザーの確認結果で判断する。
