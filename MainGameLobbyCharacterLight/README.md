# HS2ロビーのキャラ照明

マップ299000・CanonHS2_bulk_87beb58feae5248cで通常版Free Hのキャラ用ライトを強度0.32・暖色RGB(1,0.90,0.78)に合わせ、退出・H終了・無効化で元へ戻す。

背景ZIPMODのwarm-interior-v1と組み合わせる初期調整で、肌・衣装の素材やカードは変更しない。

canon_gateの個別GUID許可を使い、開始・シーン読込／破棄・設定変更イベントだけで動き、フレーム監視・ログ・独自UIは追加しない。

本来の照明リセット・体位変更でも補正値を維持し、標準の照明スライダーは利用できる。

設定はBepInEx/config/com.kks.maingame.lobbycharacterlight.cfgで変更し、ゲーム画面での色合わせはユーザーが確認する。

正式配置はKKS終了後にDeploy.ps1を実行し、元DLL・設定をゲームの外へ保存して、配置後のサイズ・日時・SHA-256と重複DLLを検査する。
