# MainGameCameraLookControl

女性キャラの標準「カメラを見る」の可動域・曲げ方・追従速度を変更します。注視の開始・終了や対象の選択はゲーム側に従います。

## 設定する場所

PlaybackBarの拡張から **首操作** タブを選びます。全設定は次の3ページにあります。

- **首・頭の可動域**: 首と頭それぞれの上下左右の限界角度に追加する量（度）。
- **曲げ方・追従**: X/Y回転の倍率・角度補正、首と頭のZ傾き、左右を向いた量に応じたZ傾き、追従速度。
- **追従範囲・状態**: 注視を継続する上下左右の認識範囲と、最後の計算状態。

PlaybackBarが使えない場面では、F1の本プラグイン設定にある「首操作の設定窓を開く / 閉じる」から同じ内容を開けます。

初期値は首の上向き可動域に10度、頭に20度、上方の追従範囲に30度を追加します。それ以外の角度追加とZ傾きは0、回転倍率と速度倍率は1です。たとえば首の上向き限界が標準20度なら、10度追加すると30度になります。実際の首と頭の配分は標準計算に従います。

各スライダーの下に単位・範囲・効果・例を表示します。「標準相当へ戻す」は追加量0・倍率1、「初期値（見上げ拡張）」は上記の初期値へ戻します。変更は約0.35秒後にBepInEx設定ファイルへ保存します。「設定を再読込」は保存済みの値を読み直します。

標準ゲーム・VR・CharaStudioを対象とします。女性キャラの標準計算が実際のCameraを対象にする場合に適用し、相手キャラなど他の対象には適用しません。VRではVRGINのHMDも対象にします。カメラ注視を使わない独自の骨制御には適用されません。

## ビルドと検証

```powershell
dotnet build MainGameCameraLookControl/MainGameCameraLookControl.csproj -c Release
dotnet run --project MainGameCameraLookControl/Tests/MainGameCameraLookControl.Tests.csproj -c Release
```

CPUテストは角度・範囲計算、例外時の標準パラメーター復元、Z傾きの累積防止、既存姿勢の保持、対象判定、および実際の3種類のゲームDLLとの接続定義を検証します。描画・実際の見上げ・スライダー入力はゲーム内で別途確認が必要です。

配布元はこのプロジェクト自身の `bin/Release/net472/MainGameCameraLookControl.dll` です。
