# H場所の自動配置

通常のComposer・HipHijack操作に接続する本番プラグイン。共用APIはMainGameHLocationCoordinates。場所配置試験タブや専用の登録・呼出操作はない。

保存済みの旧プリセットは、そのまま読み込める。保存元が不明なものは補正せず、既存画面へ状態を表示する。正しいH場所で通常の新規保存・上書き保存を行うと、マップ・H場所・女性Root・親・各オブジェクト/IKの登録元がOriginsへ記録される。L1/L2の片側上書きは他方の登録元を変更しない。

登録元A、配置先B、元のワールド姿勢Pから、共用APIでB × inverse(A) × Pを計算する。Composerの最上位は非表示の親で配置する。独立した個別IKの読込用コピーを変換し、保存原本を保持する。Composer連動IK、ボーン/HMD追従、外部所有のIKへ二重の補正を掛けない。HipHijack本体がプリセット適用から除外するBodyのON/OFF等は変えず、独立したBody目標の場所移動は他の個別IKと同様に扱う。

L1/L2の親の保存元が違う場合は読込用の端点キャッシュを共通の親へ変換する。強度による位置オフセットとゲージの位置・回転端点も、変更イベントで変換してキャッシュする。既存のルール評価はそのキャッシュを参照し、UI編集と保存には元のルールを使う。

場所移動前に実測を取得し、移動完了時にComposer、独立IK、進行中のワールド遷移、ドラッグ後の保持位置を更新する。新しいUpdate/LateUpdate/FixedUpdate、常駐コルーチンや監視タイマーはない。canon_gateが許可したHだけで接続し、終了時にパッチ・参照・配置用の親を解除する。

既存Composer・HipHijack・マップのソース/DLLと保存形式は変更しない。通常の保存先を使用し、試験フォルダへの振り分けは行わない。保存完了と登録元情報の内容を照合し、失敗・中断した組合せは補正に使わない。保留記録がある場合は、正しい場所で再保存すると更新できる。

非単位の基準スケール、Composerの動く外部ボーン親、ワールド軸モーションは補正対象外として表示する。無理に推測して適用しない。

Build.ps1でReleaseビルドと自動テストを実行する。ゲーム終了後にDeploy.ps1で導入する。旧試験DLLだけをワークスペースのバックアップへ退避して撤去する。旧試験の保存データは削除・自動移行しない。配置先・重複・サイズ・更新日時・SHA-256・既存3 DLLの不変を確認する。

本番DLLを外して再起動すると、既存プラグインの動作へ戻る。保存元JSONを削除・修復する必要はない。稼働中DLLの差替え・ゲーム起動・ゲーム操作は行わない。

1.0.1ではAllPoseRoomの選択マップ、ホテルの所有客室（201等）、AI少女モードのH所有マップから配置基準を取得する。ホテルとAI少女ではHシーン自身のBaseMapを使い、前セッションの予約マップや非稼働のマッププラグインの情報を採用しない。ホテルの保存元には客室番号を含める。

1.0.2ではHipHijack自身のBuildCurrentPosePresetSnapshot完了時に、そのセッションの女性Rootから保存元を取得する。新規・上書きとも、実際に保存するプリセットIDとマップ・H場所・位置・向きを結び付ける。起動直後の未読込一覧やComposerのオブジェクト親・編集状態に保存元取得を依存させない。保存前に一覧が並び替わってもIDで照合する。元情報が取得できなければ元情報なしの保存は行わず、状態表示へ失敗を出す。既存の保存座標に推測の保存元を後付けしない。

マップ・Composer・HipHijackのDLLハッシュによる対応版制限は行わず、DLL更新だけで場所補正を停止させない。Deploy.ps1は導入前に接続試験を実行し、AI少女モードのgate許可へ共用APIと補正プラグインの2 GUIDだけを追加する。既存の許可項目は保持する。

Composerの接続検査はゲームを起動せず実DLLに対して行う。自動テストでは、実DLLのコピーへ無関係なフィールドを追加しても接続でき、保存結果の型を変えると接続を拒否することを確認する。Deploy.ps1のComposerハッシュは配布中に元DLLが変わらないことの照合だけに使い、対応版の制限には使わない。

Logging/EnableLogsは既定OFF。OFFでは診断用メッセージの生成・収集も実行しない。診断ON時だけ、保存・適用・場所変更イベントをBepInExへ出力する。

自動テストは、製品と同じ保存モデル・JSON処理・Harmony接続・配置処理をリンクし、Unityの計算/階層代替と模擬プラグインで実行する。実ゲームの親子回転・身体の動き・通常版/VRの見た目・再起動後の結果はユーザー確認が必要。
