# 丸い手足：靴下と手袋 0.1.1

表示中の女性の身体から、二の腕・太ももの指定位置から先を表示せず、丸い縁と元の肌の浅い蓋で閉じる装備です。

## 使い方

1. 手袋から「丸い先端・手袋」、靴下から「丸い先端・靴下」を選び、着用状態にします。
2. Makerでは専用衣装を選ぶと調整窓を開きます。同じ衣装の再選択、または手袋・靴下の設定内の「丸い手足：位置を調整」からも再表示できます。通常H・VR Hでは共通UIの「丸い手足」タブで対象キャラを選びます。
3. 左腕・右腕・左脚・右脚のスライダーまたは数値欄で位置を変更します。0%は付け根側、100%は肘・膝側の、丸く閉じられる区間です。初期値は50%、腕・脚の左右連動はONです。
4. 「決定」で保持し、「閉じる」やHの共通UIで他タブへ移動したときに未確定の変更を戻します。保持した値は次にキャラカード／コーデカードを保存したときに書き込まれます。Hの「決定」はカードファイルを自動保存しません。
5. 別の衣装へ変更するか脱衣すると、対応する手足が元へ戻ります。

## 導入

KKSを終了し、配布ZIP内のBepInExとmodsをKKSフォルダーへコピーします。

同名DLLを複数配置せず、コピー後は配布元とのサイズ・日時・SHA-256を照合します。

配置によるゲートの例外追加は行いません。動作範囲は中央ゲートの許可に従い、他マップやMakerへの許可を自動追加するインストーラーは削除しました。

依存先はcanon_gate 2.4.0以降、KKSAPI、Sideloader、ExtendedSave、MainGameUnifiedUi、MainGameUiInputCaptureです。zipmodは選択用の衣装を登録し、形状は補助DLLが生成するため、両方が必要です。自動起動やゲーム操作は行いません。

## 対応範囲

- Maker・通常H・公式VR Hで、表示中の女性の身体を加工します。KKSボーンの参照と切り口の接続を検証し、標準メッシュとの完全一致は要求しません。Uncensor Selectorの身体再読込にもイベントで接続します。必要なボーンや読み出せる頂点を持たない身体、Studioは対象外です。
- 袖・ズボン・靴など他の衣装は残ります。骨・IK・当たり判定・アニメーションも残り、見た目だけを変更します。
- 肌材質・テクスチャ・UVを引き継ぎます。中央の模様は周辺の肌を伸ばしたもので、新しい皮膚模様を作る処理はありません。
- 既存衣装の身体マスクは保持し、蓋だけマスクを解除します。独自シェーダーや外部MODによる直接の材質操作は、実際の表示で確認が必要です。
- 通常のポーズ・体型変更はスキニングで追従し、毎フレームの監視や再生成は追加しません。衣装・身体の再読込、位置操作、肌の変更イベントで処理します。
- 対応外の身体・不正な切り口・生成失敗は画面に理由を表示し、不完全なメッシュへ差し替えません。他MODが取得したメッシュの所有権は上書きしません。

## 検証

`Tools/Verify-RoundedLimbClothes.ps1` で、導入済み標準身体の読み出し、zipmod生成、Releaseビルド、実データの形状テスト、実コントローラーの境界テスト、導入済みDLLとのAPI照合、配布ZIP作成を再実行できます。テスト用の身体データはローカルで抽出し、配布ZIPには入れません。

形状テストは標準身体４種類の左右の腕・脚について0〜100%の１%刻みと頂点・辺に重なる切断を検証し、穴・面の向き・ウェイト・切断先の除去を確認します。実際のBodyMeshAdapterとコントローラーを接続した検証では、元と異なる形にした身体、ブレンドシェイプ、ボーン数の差、Rendererへの差し替え、着脱、腕の回転・ねじり・拡縮後の境界も確認します。UIの実コードはIMGUIの境界を代替してドラッグ・再表示・取消・失敗時の操作を検証します。これらはゲーム内表示の証明ではありません。

ゲームは起動・操作していません。肌のつなぎ目、丸み、体型変更、腕上げ・脚曲げ、VR表示、スライダーの入力貫通、カード再読込はユーザーによる実機確認が必要です。

診断ログは `canon.kks.roundedlimbclothes.cfg` の `Diagnostics / Enabled` で切り替えます。既定OFFで、OFF時はログ専用の状態収集・文字列生成・出力を行いません。
