# RhythmSync 曲別BPM自動解析

- 未登録曲だけ先頭90秒をC#で自動BPM解析し、既存SongBpmMap.jsonへ保存する。登録済み曲は自動BPM解析しない。
- プレイバックバーのBPM右隣に「BPM解析」を追加し、明示クリックでは登録済み曲も再解析する。解析中は再押下を無効にする。
- 右Ctrlタップと手動保存を優先する。曲変更・H終了・許可失効・次Hへの古い結果を拒否し、失敗・無音は保存しない。
- 新しいフレーム監視・タイマーを追加せず、動画イベント、既存の音源変更検出経路、SynchronizationContextの完了通知を使う。
- 幅1400未満では時間・BPM・音量の列を一段下へ移し、バー全体の既存入力遮断範囲を維持する。
- Python版との比較は合成100/120/138/174 BPMおよび実音源2曲で一致し、180候補のスコア最大差は8.88e-16だった。
- 実音源SP73は自動210／保存105、SP71は自動150／保存153だった。保存値との一致は保証せず、既存値は変更していない。倍テンポ等の誤判定は右Ctrlで修正できる。
- 解析・競合・配置寸法テスト29項目、既存共通時計28624チェック、gate境界133項目、BlankMapAdd回帰161項目が成功した。回数は分離試験であり、実機検証件数ではない。
- 両プラグインのReleaseビルド成功。RhythmSyncには既存の未使用dataSize警告1件がある。gate試験は現行HotelModeソースのリンク不足を補った。
- KKS起動中のためDLLは未配置。ゲーム内の表示・解析・右Ctrl入力は未確認で、ゲームの起動・操作はしていない。
- 配置はMainGameRhythmSync/tools/Deploy-AutoBpm.ps1でゲーム終了と重複DLLを確認し、各プラグイン自身の成果物からコピーしてサイズ・日時・SHA256を照合する。
