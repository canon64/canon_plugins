# 体付近の小物取得と注射器の姿勢

- 今回の実機ログはディルド0.3.16のロードを確認しており、旧DLL未配置ではなく追加の競合調査が必要だった。
- 導入済みKKS_MainGameVR.dllのCaressControllerはOnTriggerEnterからUpdateLockを呼び、体に接触するとグリップ押下前に有効な操作権を取得する。前版の解放待ちだけの処理ではこの操作権を譲れない。
- 全4小物の共有VrItemFocusは、小物自身の操作許可・距離判定後に、現在の操作権が同じ手のCaressController所有物と一致する場合だけ、そのReleaseLockを呼んで愛撫のマウス押下と所有参照を解除してから小物の操作権を取得する。保持中の別アイテムは奪わない。
- 注射器は掴み時に設定の回転へ戻す処理を撤去し、ワールド姿勢を保つ。刺入中の握り直し時もその手への相対姿勢を保存し、抜いて戻す際に使用する。設定欄の保持姿勢を明示変更する機能は維持する。
- ディルドは既存の動作診断がONの時だけ、グリップ押下時の距離外・操作権競合・成功を記録する。既定OFFと現行設定を維持し、OFFでは診断用の状態取得や文字列整形を行わない。
- 実機で体に接触した状態の小物取得と注射器の見た目は未確認。修正版はビルド・配置の状態を別途記録する。
