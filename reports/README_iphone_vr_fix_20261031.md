# iPhone 1.2.1 VR描画・撮影音修正

- 実機ログに出ていた `Can't use AnimationClip::SetCurve at Runtime on non Legacy AnimationClips` は、カメラUIのSetCurveより後でlegacyを指定していたためで、生成直後に指定するよう修正した。
- カメラUIの透明度0から1への遷移が作成されず、画面が透明のままになる経路を修正した。
- 背面カメラの描画ごとにCanvas.enabledを切り替える処理を撤去し、固定したCanvasRenderer一覧のcullを一時保存・復元する方式に変更した。
- 元の画面、黒い縁、ライブ映像の間隔を40/80マイクロメートルから300/600マイクロメートルへ広げ、深度の競合を減らした。
- 写真保存成功時のシャッター音、録画開始と停止の異なる音を端末の3D AudioSourceで再生し、F1のPhone.Camera/CaptureSoundVolumeで音量を設定できる。
- グリップ解放とトリガー解放では録画を停止せず、フォーカス喪失でも録画を止めず、もう一度のシャッター操作またはBで停止する。
- 録画中は手放してもアイドルロックせず、同じ録画とカメラ画面を保持することを製品ルーター試験に追加した。
- 製品Releaseビルドは警告0・エラー0、VR・バー62項目、製品ルーター25項目が成功した。
- 実機ログのPlaybackHelpWindow.DrawWindow由来のNullReferenceExceptionは別プラグインのため、今回の変更対象に含めていない。
- 起動中のKKSを確認したため配置待ちで、実機でのちらつき解消、UIの見え方、撮影音の聞こえ方は未確認。
- 追加報告の注射器はVRトリガーに補充の分岐がなかったため、抜いた空の注射器ではRefillへ接続し、補充・投与動作中の再入力を拒否するよう修正した。
- 注射器もReleaseビルド警告0・エラー0で、製品VRハンドラー17項目が成功し、両DLLともゲーム終了後の配置待ち。
- 追記：PCフォーカスとVRフォーカスの区別も修正し、KKS終了後に両DLLの配置とサイズ・日時・SHA-256照合を完了した。記録は `vr-interaction-deploy-20261031-110157-022/verification.json`。
