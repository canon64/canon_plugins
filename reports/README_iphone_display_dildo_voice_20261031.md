# iPhone描画とディルド音声の修正

- iPhone 1.2.2は、端末へ重ねたCanvasを背面カメラごとに非表示へ切り替える方式を撤去し、固定した専用描画面へUIとカメラ映像を合成して端末の画面メッシュへ貼る。
- ディルド0.3.14と音声側0.4.7は、条件達成時にゲーム側の通常音声の終了を待たずに開始し、読み込み中の通常音声も取り消す。
- 再生中のディルド自身の音声は種類にかかわらず最後まで保護し、注射器音声中はディルド音声の要求を破棄する。
- 同時に複数の条件を達成した場合は絶頂・強いピストン・通常ピストンの順に選び、通常ピストンの再試行待ちで強いピストンを止めない。
- 呼び出し・ギズモ・撮影・録画・写真保存先は維持し、監視や常時ポーリングは追加していない。
- 正規Release成果物3本のビルドと境界回帰を実施し、KKS稼働中のため配置は保留、実機のちらつき・音声開始時刻・音声の保護はユーザー確認が必要。
