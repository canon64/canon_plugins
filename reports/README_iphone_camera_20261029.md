# フリーH用iPhoneカメラ

新規ソースは `MainGameIPhoneCamera`、旧MainGamePhonePreviewやスタジオ用プラグインのコード参照はなく、導入済みearthship iPhone Xの実メッシュを使う。

- 本体の背面カメラ映像を実画面部分へ表示し、古い待受画面を画面専用マスクで覆い、本体・背面の素材は維持する。
- 公式VRの左右別Grip_Press押下／解放とAxis1_Press押下へ接続し、近くでグリップを押している間保持し、同じ手のトリガーで1枚撮影する。
- 保持はTransform親子付けで追従し、終了・無効化・破棄で全購読と生成物を片付け、フォーカス／追跡喪失・切断で保持を解除する。
- 保存先は `F:\kks\UserData\cap`、形式はPNG、既定は886×1920の縦長画像で、同時刻でも識別子付きファイル名とCreateNewにより上書きを防ぐ。
- UIは総合UI／PlaybackBarの「iPhoneカメラ」タブで、表示／非表示ボタンを持ち、表示するたびに現在の視点の45cm前へ配置し、H開始時は非表示とする。
- 上中央の黒い切り欠きの左右下角を半径3mmの円弧で丸め、元の本体外周は維持する。
- canon_gateへ実開始／終了を登録し、既存AllPoseRoom／個別例外の許可に従い、中央の例外設定は変更していない。
- 実KKS DLL参照のReleaseビルド成功、製品コードのVRイベント処理と実素材の画面メッシュ生成を境界テストで確認した。
- Update・LateUpdate・FixedUpdate・常駐コルーチン・タイマー監視の追加はなく、ライブ映像はUnity Cameraの通常描画を使う。
- KKS・公式VR・Studioの終了を確認して新規DLLを配置し、専用bin成果物とサイズ・更新日時・SHA-256が一致し、同名DLL重複がないことを配置スクリプトで確認する。
- VR実機の表示・グリップ／トリガー操作・実際のPNG保存は未確認で、ゲームを起動・操作する自動検証は行っていない。
