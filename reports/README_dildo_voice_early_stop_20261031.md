# ディルド音声の途中停止修正

- 音声側0.4.7では通常衝撃音要求を対象外モーションで拒否するときにCancelImpactCueForMotionを呼び、共有音声プレーヤーで再生中のディルド音声までフェード停止する経路が残っていた。
- 通常衝撃音の要求元はMainGameVoiceImpactBoostとMainGameVrHipIkVoiceImpactBoostで、ディルドの動作中にも要求が来うる。
- 0.4.8では要求拒否時のキャンセルを撤去し、モーション条件のキャンセルは再生中の深い挿入・通常ピストン・強いピストン・絶頂音声へ適用しない。
- 明示OFF、注射器優先、セッション終了、破棄の後始末は維持し、注射器音声中のディルド要求拒否も維持した。
- 製品のCancelImpactCueForMotionを直接リンクした境界試験で、繰り返すキャンセルがディルド音声へ停止・フェード指示を出さず、自然終了まで維持し、通常衝撃音のキャンセルは有効なことを確認した。
- 製品ビルド成功、既存の未使用フィールド等18警告、回帰ハーネス9498項目成功、毎フレーム監視の追加なし。
- 11:47にゲーム終了を確認して0.4.8を配置し、正規ビルドとのサイズ・日時・SHA-256一致と重複なしを確認した。実機で最後まで聞こえることは未確認。
