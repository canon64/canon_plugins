# ディルド・注射器の再保持修正

- ディルド0.3.15は同じ手の新しいグリップ押下で古い保持状態を解消し、取り逃した解放通知が次の保持を妨げないよう修正した。
- ディルドの距離判定は描画用に拡大したSkinnedMeshRenderer.boundsではなく、実際の曲がった8本の骨の線分と設定済みの握り位置を使用し、他の小物付近での誤取得を減らした。
- VRで保持を始めた時にデスクトップ用ギズモを閉じ、同時に位置を書き換える競合も防いだ。
- 注射器1.5.5は刺入後にトリガーが残ってSafeReleaseが完了していない時でも、自分の解放待ちロックのみを再利用して保持できるよう修正した。
- 注射器は握り直しても刺入状態を保ち、投与・抜去・再刺入を同時には行わず、次のトリガーで投与する。
- 手の移動通知、毎フレーム監視、距離ポーリングは追加せず、既存のグリップ押下時にだけ判定する。
- ディルドの製品保持境界テスト14項目、注射器の製品VR境界テスト19項目が成功し、両製品のReleaseビルドは警告0・エラー0。
- 11:47にゲーム終了を確認して音声側0.4.8とともに配置し、正規ビルドとのサイズ・日時・SHA-256一致と重複なしを確認した。実際のVR入力・描画・音声は未確認。
- 刺入対象の親へ戻す解放と、解放待ち操作権での即時再保持を含む追加試験で、ディルドの製品VR境界テストは17項目成功した。
