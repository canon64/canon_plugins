- `comparison.json` は271項目一致、失敗0件で、`before-save.json`、`after-reenter.json`、実保存JSONを比較する。
- 女性ゲージ75、涙2、ネイティブ精液全5部位2、衣装番号2、仰向け愛撫クローン、客室配置と向き123度が再現した。
- MODの涙・よだれ・唾液・汗・赤み・精液などの各プロパティと、手動指定の制御状態を保存・復元した。
- 実際に出して位置を変更したディルド・iPhoneの表示・位置・向き・倍率・設定を確認し、ディルドの自動往復ONと速度0.7も再現した。
- 小物10プロバイダーの保存と読込結果はすべて成功したが、全10種類を表示して個別配置する実機試験を行ったという意味ではない。
- 愛撫の本体速度は無操作で減速するため、保存前の別時点の値ではなく、実保存JSONの値を復元後と比較した。
- `comparison-before-save-reference.json` は時点の違う速度2項目を誤って比較した初回結果を保全したもので、同時保存値の不一致ではない。

- canon_gateは配置後に依存ビルドでbinが更新されたため、実機試験に使った配置時SHA-256との一致と、現在のbinとの差をmanifestで分けて記録した。
- 他の客室への入室・登録変更は行わず、元の201データは `201-before-api-*.json` に退避した。
