# MainGameVrNeckGrab

VRの首掴み、30秒後の人形化、覚醒を1本のDLLで扱います。

## 操作

- 女性の首から既定12cm以内でトリガーを押すと、一番近い首を優先して掴み、その女性のセリフを停止します。Colliderへの接触は不要です。喘ぎ声・息遣い・他の女性の声は止めません。
- 同じ押下は標準のキス・胸の愛撫へ渡しません。首の範囲外や別の手の通常操作は維持します。既に別アイテムが操作権を使っている場合は奪いません。
- 愛撫の実際の左右の手モデルを複製し、指を閉じて首に残します。キャラの首や頭を動かす機能ではありません。
- 手は従来の向きからY軸180度反転後、Z軸90度で横に倒します。手首ではなく掌の中心・接触面を、呼び出し時に一度だけ採取した実際の首の肌表面へ合わせます。肌を特定できない場合は固定距離で代用せず通知します。
- トリガーを離すと掴みと計時だけ解除します。首の手は残り、首スロットの「解除」または標準の全アイテム解除で外せます。胸などの既存スロットは使用しません。
- 連続30秒保持すると、触れた女性だけを一時的に人形化します。以後はトリガーを離しても覚醒まで維持します。
- 人形化中の女用感度は維持し、本来の正の増加量を覚醒へ回します。男用は変更しません。ネイティブの感度ロック中は強制加算以外を増やしません。
- 覚醒100で人形化と保持による音声抑止を解除します。首の手は残ります。再度掴む場合はトリガーを離して押し直してください。
- 覚醒は既存の女用の内側に黄色の独立した弧として表示します。男用・女用の画像、枠、位置、ロック操作は変更しません。人形化中だけ対象名と覚醒を表示します。

## 構成と設定

- 製品は `bin/Release/net472/MainGameVrNeckGrab.dll` のみです。既存プラグインのDLLを変更したり、参照DLLを同梱したりしません。
- 必須依存は canon_gate 2.4以降、MainGameNotifications、導入済みKKS_MainGameVRとそのVRGIN/OpenVRです。
- GUIDは `com.kks.maingame.vrneckgrab` です。中央gateがこのGUIDを許可した次のVR H開始から動きます。許可リストや導入済みDLLは本実装では変更していません。
- BepInEx設定で有効・無効、首を優先する距離（既定12cm、2～25cm）、次回掴みの手倍率、診断ログを変更できます。距離は次の押下から適用されます。診断は既定OFFです。再有効化は次のH開始から適用します。
- 導入済みMainGameDollModeの `config.json` を読んで表情・目・追加効果・W/Sの動きの値を一時適用します。設定ファイルは読み取り専用です。未導入なら同形式の既定表情を使います。
- MainGameDollMode.dllへのバイナリ依存はありません。追加液体効果・渦目・目の画像は、それぞれ設定された既存サービスが必要です。不足や一部適用・復元失敗は共通通知に出します。
- 既存の人形モードが適用中の女性には重ねて開始しません。既存モードの明示適用時は今回の一時状態を先に戻して引き渡します。

## 処理の境界

- 首との距離はトリガー押下時だけ調べます。標準愛撫が先に押下を読んだ場合も首へ振り分け、SteamVR側との重複通知は同じ押下として扱います。解放、追跡・フォーカス喪失、終了で入力の取得状態を解除します。
- 取消可能な一度だけの30秒待機、実際の感度変更箇所、キャラの表情・アニメーション値の変更箇所に接続します。首判定用のCollider、Rigidbody、接触通知への依存はありません。
- 新しいUpdate/LateUpdate/FixedUpdate、移動通知の購読、フレーム監視や再適用ループはありません。指の閉じ動作は有限のアニメーションで、完了イベントで姿勢を残します。
- 元の感度値は複数女性で共有されるため、標準HandCtrlの女性や処理の実引数から刺激元を区別します。個別の刺激元を持たないゲーム共通処理はメイン女性の処理として扱います。女用の描画と判定には人形化時点の値を渡します。
- ネイティブの会話ロードを個別に識別し、掴み前に読み込み中だったセリフも取消します。取消されたロードの完了抑止だけはH終了後も有効で、古いセリフを復活させません。
- 外部音声ブリッジの会話・待機列・非同期ロードを対象女性だけ停止します。独立した喘ぎ声用AudioSourceの停止APIは呼びません。
- 覚醒、無効化、H終了で今回変更した外見と追加効果を復元します。途中の一項目が失敗しても残りの復元と操作権解放を続けます。

## ビルドと確認

```powershell
dotnet build MainGameVrNeckGrab/MainGameVrNeckGrab.csproj -c Release
dotnet build MainGameVrNeckGrab/Tests/Tests.csproj -c Release
./MainGameVrNeckGrab/Tests/bin/Release/net472/NeckGrab.Tests.exe
dotnet build MainGameVrNeckGrab/Tests/NativeContracts/Contracts.csproj -c Release
./MainGameVrNeckGrab/Tests/NativeContracts/bin/Release/net472/Contracts.exe
```

境界試験は製品の状態遷移・Harmonyフックのソースをリンクし、タイミング、音声分類、実フィールドへの書込み、対象分離、非同期取消、後始末を試験します。通常版・公式VR版の導入済みDLLの型とシグネチャも別途検査します。

ゲーム内の手と首の位置合わせ、握る見た目、首スロットの配置とVR選択、3本の弧の実表示、聴感は未確認です。ビルド・自動試験を実機での成功とは扱いません。配置は別途指示後、ゲーム終了を確認して正本のDLLをコピーし、サイズ・日時・SHA-256と重複なしを確認します。
