# ホテル4F大浴場・素材と三面図 v01

採用中のコンセプトを元にした素材と設計検討用の図であり、実装済みマップの画像ではない。

石床・木材・浴槽タイル・水面の4種類を `textures/<種類>_main.png` と `textures/<種類>_normal.png` に収録する。

メインは色用のsRGB、ノーマルは接線空間RGBの+Y形式・linearとして扱い、UnityではTextureType=NormalMap、convertToNormalmap=falseで取り込む。

石床は床・浴槽縁・床一体の低い段差、木材はステージ・天井、タイルは浴槽の底と内壁、水面は別の水シェーダーへ割り当てる。

KKS標準の `Lux Water/WaterSurface` が外部ノーマルを受け取れることを実資産から確認済みで、水面ノーマルは `_BumpMap` 用の候補とする；青い `water_main.png` は同シェーダーの泡マスク用 `_MainTex` には使わず未使用案として保存し、詳細は `../../WaterInspection/FINDINGS.md` を参照する。

画像はimagegenで生成した初稿で、凹凸の位置合わせと反復時の継ぎ目は材質適用時の確認が必要；ゲーム内の描画は未確認。

`three_views.png` は上面・正面断面・右側面断面の設計検討用三面図で、寸法は提案値として扱い、厳密な施工図・実測図として使わない；図内の水深0.60m表記は床から浴槽底までの深さを意図しており、水面が床下0.10mなら実水深は0.50mとなる。

置き椅子は禁止し、床と連続した高さ約15cmの低い段差を使い、湯船と乾いた床を少数の大きな曲線で入り組ませ、ステージまで床で直接近づける構成を維持する。

生成プロンプトは `generation_prompts.json`、画像寸法・ハッシュ・ノーマルベクトルと反復境界の計測結果は `asset_audit.json` に収録する。
