# AI少女モード専用プレイバックバー

「:」キーで表示・非表示。「設定」で既存プラグインの拡張タブを開く。再生・一時停止・停止・前後送り・シーク・音量・ループ・マイリスト／プリセット選択は既存VMD APIを使用する。再生一覧はページ分割する。

BlankMapAddへの参照・依存は追加せず、部屋タブも作らない。既存UnifiedUiのタブ描画をそのまま埋め込み、入力範囲とドラッグは共通UiInputCapture APIで保持する。寸法・表示初期値・キー・ページ件数はparameters.jsonのaiMode.playback設定で変更できる。

バー表示中はカーソルを解除し、非表示・会話・設定・H移行・フォーカス喪失・破棄で保持を解除する。H読込完了とモード復帰時は表示状態を引き継ぐ。新しいUpdate等の常駐監視は追加しない。

manage.py buildは数値監査後にVMD・AIモードをビルドし、コンテンツ試験と専用バーの入力境界試験を行う。manage.py deployはAIモードと対応VMD DLLを各自のRelease成果物から同時に配置する。KKS起動中は配置しない。

自動試験は代替Unity UIによる境界検証。実際の見た目、シーク、タブ内スライダー、H中の入力、閉じた後の歩行復帰はユーザーによる実機確認が必要。
