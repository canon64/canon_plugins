# デスクトップディスプレイ

Windowsデスクトップをゲーム内の枠付き平面ディスプレイに映す、通常版・公式VR向けのH専用プラグイン。

VRでは画面の表面・端から18cm以内で左右いずれかのグリップを握ると持てる。掴んだ姿勢のまま手に追従し、離すとその場に固定する。保持手のスティックを上へ倒すと10％拡大、下へ倒すと10％縮小し、中央に戻して再び倒すと次の段階へ進む。幅は0.1〜20mで縦横比を保ち、変更を保存する。保持手の左右は前／次のモニターへ切り替え、端では循環する。中央へ戻すまで同方向へ連続切替しない。斜め入力は強い軸を採用する。切替で掴み・配置・画面幅・一時停止状態は維持する。表示中・一時停止中・取得エラー後も掴み直せる。

VRのPCマウス操作は右手から画面表面への交点が50cm以内の時だけ有効になる。水色の線は交点で止まり、Windowsカーソルは毎フレームその先端へ追従する。Aで左クリック、Bで右クリック、スティック上下で縦スクロール、左右で横スクロールする。スティックは中央へ戻して倒すたびに1ノッチ送る。Aを押したまま動かすドラッグに対応する。範囲外・画面外・裏側へ出ると線を消し、押下中のボタンと操作権を解放する。

掴んでいる間はマウス操作を止め、保持手の上下をサイズ変更へ使う。一時停止・取得失敗・無効化・削除・VRフォーカス喪失・追跡喪失・H終了ではWindows側の押下を解除する。設定タブの「PCマウス操作」をOFFにすると専用A/B・スティック入力と水色の線を停止する。表示中の専用入力を通常VR操作へ戻す場合もこのチェックを外す。Touch/Indexの物理A/Bと右スティック用のSteamVR設定を配置するため、更新後はゲームの再起動が必要。

PlaybackBarの「ディスプレイ」を左クリックすると、設定した出現位置へ呼び出し、次の左クリックで共通ギズモを表示する。以後は呼び戻しとギズモを交互に実行し、右クリックで削除して画面取得を停止する。

「ディスプレイ」タブの「出現位置」で、左右・上下・呼出距離をスライダー＋数値入力で設定する。呼び出した時の視点基準で右・上が正、呼出距離が前方の距離。初期値は左右・上下0m、距離0.5m。既存の保存距離は維持する。調整中はその呼び出し時の視点基準で実物へ仮反映し、スライダーを離した時・Enter・数値欄のフォーカスを外した時に保存する。未表示なら次の呼び出し時に反映する。調整幅は±0.25/1/5mから選べ、数値入力した左右・上下の周辺へスライダー範囲を合わせる。頭の移動への常時追従は追加しない。

設定は「出現位置」「画面サイズ」「映すモニター」「上下左右のクリッピング」「画面プリセット」「画質・更新頻度」「VR・マウス操作」に分け、初期状態ではすべて閉じる。見出しを押して必要な一項目だけ開き、別の項目を開くと前の項目は閉じる。同じ見出しを押すと閉じる。呼び出し・ギズモ・削除・一時停止／再開・現在の状態は常に表示する。

UIとVRのどちらで選んでも、最後のモニターを保存して次の呼び出し・再起動で復元する。保存識別子は `DISPLAY1` の形式を使い、古いWindowsパス形式の保存名も読み取る。モニター別の既存クリッピング設定はそのまま引き継ぐ。未接続のモニターの設定も削除しない。

「画面プリセット」は名前を入力して「現在の画面をこの名前で保存」を押す。モニター・上下左右の切り取り・画面幅を保存し、一覧の名前を押すと復元する。同名で保存するとそのプリセットを更新する。データは通常のプラグイン設定ファイルに永続保存する。元モニターが未接続なら現在の画面を変えずに理由を表示する。保存データの読込失敗時は元データの上書きを止める。

「画面プリセット」内の「モニターごとの自動適用」で、各モニターに使うプリセットを選択する。そのモニターで保存されたプリセットだけが候補になる。保持中の左右スティック切替・UIでのモニター切替・次回の画面呼び出し時に、選択した切り取りと画面幅を自動適用する。割り当てはモニター別に保存する。保存した新しいプリセットは、そのモニターへ自動的に割り当てる。他のモニターの割り当てを設定するだけでは表示中の画面を変更しない。「指定なし」はそのモニターの最後の手動切り取りを使う。プリセットの自動適用は手動切り取りの保存値を上書きしない。割り当てたプリセットが見つからない時も設定を消さず、手動切り取りを使う。

総合UIの「ディスプレイ」タブでモニター選択、一覧の再取得、一時停止・再開、カーソル表示、画面幅、呼出距離、移動・回転を操作できる。一時停止中は最後に取得した画像を表示する。

上下左右のクリッピングは各モニター別に保存され、初期値は0％。スライダーと数値入力で指定し、スライダーを離した時・Enter・数値欄からフォーカスを移した時にまとめて反映・保存する。ドラッグ中は数値だけ変更する。内容の大きさを保ったまま表示面と枠を切り詰め、画面取得も残った矩形だけに限定する。クリック座標も同じ矩形を使う。最低1画素は残す。

初期設定はメインモニター・長辺1280px・上限15fps。5/10/15/30fpsと640/1280/1920pxを選択でき、縦長モニターも縦横比を保つ。設定は `BepInEx/config/com.kks.maingame.desktopdisplay.cfg` に保存する。

起動時とH開始時は非表示。canon_gateが許可したHで、呼び出した画面が描画される時だけWindows GDIからピクセルを取得し、BGRAテクスチャへ転送する。同一フレームの複数カメラ・左右眼からの重複取得を抑え、取得頻度は既定15fpsを維持する。

毎フレーム処理は、表示中・取得動作中・PCマウスON・追跡有効・未保持の時の既知の画面との交点判定。50cm外でも接近を検知するため判定だけは続け、操作できる時だけ線とカーソルを更新する。位置が同じなら線の書き込みとOS入力送信を省く。Windows画面情報・送信バッファ・固定ラベルは再利用し、毎フレームの配列・文字列生成や画面・部屋・シーン探索は追加しない。ギズモ・総合UI・入力保護・VR本体の既存更新は今回変更しない。定期タイマー・常駐コルーチン・手の移動通知購読も追加しない。

削除・無効化・H終了・破棄で画面取得、GDIハンドル、テクスチャ、素材、生成物、ギズモを解放する。取得エラー時は停止し、UIに原因を表示する。モニターを抜き差しした後は一覧を再取得する。

画面に見えている内容を取得するため、同じモニターにゲームが映っているとゲーム自身も映る。別モニターのアプリを映す場合は、そのモニターを選ぶ。最小化したアプリの内容、DRM保護映像、セキュアデスクトップ、排他的全画面の取得は保証しない。ブラウザーはPC側で開いている画面として映す。

必要DLLはcanon_gate 2.4.0以上、MainGameUnifiedUi、MainGameUiInputCapture、MainGameTransformGizmo。AllPoseRoomとホテルHは中央gateの規則で許可され、通常の部屋は既存の個別例外設定に従う。Maker・Studioは対象外。

製品ビルドは `dotnet build MainGameDesktopDisplay/MainGameDesktopDisplay.csproj -c Release`。製品はこのプラグイン自身の `bin/Release/net472/MainGameDesktopDisplay.dll`。PlaybackBarのボタン追加にはMainGameBlankMapAddの製品DLLも必要。

`Tests/NativeCapture.Tests.csproj` は実Windows上のモニター列挙、画素取得、BGRAと上下方向、カーソル取得、反復解放を検証し、画像ファイルを残さない。`Tests/Lifecycle.Tests.csproj` は製品の入口を境界代替で実行し、許可・拒否、二重開始・終了、部分失敗、世代失効、再開・削除を検証する。これらはKKS内の描画と入力の実機確認を代替しない。
