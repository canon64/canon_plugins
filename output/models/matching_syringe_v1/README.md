承認された注射器のイメージを元にした可動モデルで、透明な筒・濃い紫の薬液・黒いピストン・銀色の押し子・中空の斜め刃先を別部品として作成している。

Syringe.blendはサブディビジョン2段を保持した編集用データで、Syringe.glbとSyringe.fbxは1段を評価した可動モデルを書き出している。

Syringe_ROOTのInjectionを0から1へ変更すると押し子と黒いピストンが40.5mm前進し、薬液が針側を基準に縮む。

タイムラインは24fpsで1フレームが満タン、73フレームが投与完了、97フレームから補充し、169フレームで満タンへ戻る。

目盛りは1024x4096pxの透過PNGとしてtexturesに保存し、BLEND・GLB・FBXにも同梱している。

全長約166.5mm・筒の外径16mm、針の方向はローカル+Z、原点は筒の中央で、ゲーム側の入力処理とは独立したモデルとして保存している。

既存のゲームテストエディターは今回の実メッシュを表示し、投与位置と薬液の透明度を操作でき、薬液ボトルも同じ画面へ読み込める。

エディターの透明表示は角度で描画順が入れ替わらないよう固定したリアルタイム表示で、Blenderの屈折・吸収によるレンダーやKKSでの描画とは区別する。

KKSへの差し替えとVRでの実機確認は行っていない。
