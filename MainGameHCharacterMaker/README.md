# MainGameHCharacterMaker

フリーHのPlaybackBarから、今いる女性キャラの顔・体型・髪・瞳・化粧・肌を編集し、キャラカードを保存するプラグインです（0.3.0）。

## 操作

1. AllPoseRoomのフリーHに入り、画面下部のPlaybackBarを表示します。
2. 「総合UI」の右隣にある「キャラメイク」を押します。
3. 女性キャラと「体型」「顔の形」「髪」「瞳・眉」「化粧」「肌・体」のタブを選びます。
4. パーツは部位を選び、名前・ID検索とサムネイル一覧からクリックして変更し、色はRGBAスライダーと数値欄で調整します。
5. パーツ・色の「元に戻す」「やり直す」は、その女性キャラの直前の操作へ戻り、連続する色ドラッグは一操作として扱います。
6. 「決定して閉じる」でこのH中の編集を確定し、「取消して閉じる」で数値・パーツ・色の未確定編集を戻します。
7. 「選択キャラをfreeHへ保存」で、選択中の女性の現在の編集結果を`F:\kks\UserData\chara\female\freeH`へ新しいPNGカードとして保存します。

保存は窓を閉じずに行え、日時・キャラ名・識別子付きのファイル名で元カードや前回のカードを上書きせず、保存後に窓で取消しても保存済みカードは残ります。

PNGの見本画像は元カードの画像を使い、なければ顔画像、それもなければ同梱の共通画像を使うため、編集後の姿を新たに撮影する機能ではありません。

バーのボタン列が画面幅に収まらない場合は、ボタン列を横スクロールしてください。

## 対応範囲

- 標準の体型44項目、顔52項目、胸の柔らかさ・重さ・乳輪サイズの計99項目に対応します。
- 標準メイク画面全体の移植ではなく、専用の編集窓からゲーム本来の反映関数を呼びます。
- H中の女性を編集対象とし、女性2人の場合は選択を切り替えて編集できます。
- 数値は標準値の100倍を%で表示し、範囲外の既存値を開いただけで丸めたり書き戻したりしません。
- スライダー幅は現在値の周辺へ合わせられ、直接数値入力では有限値を反映します。
- 確定は現在のH中の外見へ反映するもので、キャラカードの保存ではありません。
- 髪は後ろ髪・前髪・横髪・オプション髪と、基本色・根元色・毛先色を編集できます。
- 瞳は左右別に種類と色を変更し、眉・上下ハイライト・上下アイラインも種類と色を変更できます。
- アイシャドウ・チーク・口紅・唇の輪郭・ほくろ・鼻の陰影・顔ペイント2枠を編集し、衣装ごとの化粧が有効な場合は実際に表示される化粧を変更します。
- 顔と体の肌質・日焼け・体ペイント2枠・乳首・アンダーヘアと、肌の基本色・陰影色・爪色を編集できます。
- パーツ候補は導入済みMODを含むゲームの登録一覧を利用し、一覧は操作時に取得・検索し、サムネイルは表示ページの12件だけ読み込みます。
- 頭部モデル全体の交換、衣装・アクセサリー・性格・MOD独自項目の編集は含みません。
- Material Editor・ABMX・オーバーレイ等の独自データを他キャラからコピーする機能は含まず、特殊シェーダーでの見た目と他MODとの競合は実機確認が必要です。

## 寿命・復元・入力

`canon_gate`の許可されたH開始でキャラを取得し、H終了・無効化・破棄では未確定変更を戻して入力を解放します。

取消では実際に編集した数値・パーツID・色だけを戻し、Hが進行中に更新する脱衣・表情・視線などの状態を保存時点へ巻き戻しません。

髪はゲームの同期交換関数を使い、H終了後に読み込みが遅れて適用される処理を追加していません。

キャラ・顔体型配列・髪データ・有効な化粧データが交換された対象は編集を拒否し、古い履歴を別の対象へ適用しません。

パーツ・色の取消で一部の反映が失敗した場合は他項目の復元も試み、H中は窓へ失敗を表示して取消を再実行できます。

身長・胸サイズなどの変更時には、H用AnimatorパラメーターとMotionIKを更新します。

共通入力APIへ窓の範囲を登録し、ドラッグ中は範囲外でも入力を保持し、フォーカス喪失で解除します。

常時監視・毎フレームの探索・再適用処理と、新しい診断ログは追加していません。

一般のフリーHへ無条件に許可する設定変更は行わず、既存の門番に従うため、通常の入口はAllPoseRoomのPlaybackBarです。

## カード保存

保存ボタンを押した時だけ、選択キャラの実際のChaFileをゲーム標準のSaveCharaFileへ渡し、KKSAPIとExtendedSaveの保存イベントを通します。

保存中だけ現在の衣装・衣装別化粧を出力対象へ差し込み、PNG画像と新カードの識別子を設定し、成功・失敗のどちらでも元の参照・画像・識別子へ戻します。

出力のPNG・キャラカード目次・必須データ・既存MODの追加データの有無を確認してから最終ファイル名へ移動し、途中で失敗した出力はカード一覧に残しません。

保存前後にHの許可と対象の同一性を確認し、H終了や対象交換後に古い保存処理を確定しません。

追加MODの保存対応は各MODの保存イベントに従うため、実機では保存カードを読み直して外見と追加MODの状態を確認する必要があります。

## 検証

Releaseビルド、実ゲームDLLへの参照コンパイル、数値とパーツの編集・復元・実GateApiのPermit失効・二重開始終了・保存先・保存失敗・同名衝突・失効後の出力拒否など62項目の境界検証に対応します。

境界検証のUnity側はモデルであり、ゲーム内の描画・入力・体位との整合や、他MODとの競合が検証できたことを意味しません。

実機では、既存ボタンから各タブが開くこと、髪・左右瞳の交換、検索とページ送り、色スライダー・数値入力、元に戻す・やり直す・取消・確定、女性切替、入力貫通防止、H終了後の入力復帰を確認する必要があります。

保存機能では、freeHへPNGが増えること、そのカードをMakerや次のHで読み直して編集した顔・体型・髪・瞳・化粧が戻ることを確認してください。

## ビルドと配置

`MainGameBlankMapAdd`を先にReleaseビルドし、次にこのプロジェクトをReleaseビルドします。

新規DLLはこのプロジェクト自身の`bin/Release/net472/MainGameHCharacterMaker.dll`を使い、ボタン追加済みの`MainGameBlankMapAdd.dll`と一緒に配置します。

ゲームが終了した状態で`Deploy.ps1`を実行すると、既存DLLのバックアップ、重複検査、コピー、サイズ・日時・SHA-256照合を行います。

既存ボタンが導入済みの環境では、`Deploy.ps1 -PluginNames MainGameHCharacterMaker`で今回の編集プラグインだけを更新できます。
