# ロウソク

赤いロウソクを通常H・公式VRのPlaybackBarから呼び出し、傾けて蝋を垂らす小物です。

- 左クリックは「視点前に呼び出し→ギズモ表示」の交互操作、右クリックはロウソクだけを削除します。
- VRは近くでグリップすると姿勢を保って掴み、離すとその場所へ固定します。
- 直立から45度までは滴下せず、初期値は水平で平均約1.5滴/秒から傾けるほど頻度が上がり、135度以上で消火します。
- 炎は前版の半分（初期版の2.5倍）の大きさで、黒い芯の先端から世界の上方向へ伸びます。
- 炎の粒子は芯の先端へローカル固定し、速度を付けません。上向きのスプライトの下端を芯に合わせるため、保持中に動かしても古い粒子が本体の中や下へ取り残されません。
- 「芯・炎の高さ」は初期値18mm（芯の付け根から）、6〜40mmで調整できます。芯と炎の根元を一緒に動かし、縦固定の描画で炎を上へ伸ばします。
- 蝋の滴下位置は本体上端の溶けた縁で、傾けた方向の低い側から落ちます。芯・炎の高さを変えても滴下位置は動きません。
- 滴下間隔と一滴の量は毎回変わり、同じ角度では長く溜めた滴ほど大きく落ちます。角度による平均流量は保ち、滴の体積と付着面積にも量を反映します。
- VRでの再点火は、135度未満へ戻してから保持している手のトリガーを新たに引きます。
- 角度を戻すだけ、トリガーの押しっぱなし、反対の手のトリガーでは再点火しません。
- 「ロウソク」設定タブに滴下頻度、一粒の量、ばらつき、芯・炎の高さをそれぞれスライダー＋数値入力で用意します。一粒の基準体積は旧版の3倍、ばらつき最大では約0.08〜2倍の間隔と量です。水平・頻度1倍ではランダム待ちの最長は約1.33秒です。
- 付着した赤い蝋はロウソクを削除しても残り、全消去操作かH終了で消えます。
- 肌だけが声・表情の反応対象で、同じキャラの反応は最低2秒間隔です。
- 本体・落下中の蝋は赤い不透明材質を使い、深度を書き込みます。
- 付着はMagicPaint本体のMeshProbe・SkinSurfaceによる接触・UV描き込み・更新処理をAPI経由で使います。ロウソク独自の肌メッシュ処理は持ちません。肌→落書き→蝋の順で、それぞれの全消去は他方を残します。
- 読み取り可能なスキンには、接触した実際の面をサンプリングした盛り上がりを試作します。「蝋の厚み」はスライダー＋数値入力で0〜5mm、初期値1.2mmです。付着済みの蝋にも即反映し、0ではUV描画だけを残します。肌と同じボーンへ結び、全消去・上限による破棄・H終了で除去します。読取不可のスキンはUV描画だけを保ちます。ボーンの移動・回転は境界テストで確認し、実機での体型変形や見た目は未確認です。
- 反応音声はキャラごとのゲーム標準の通常音声・呼吸・短い呼吸テーブルから、通常の台詞とキスを除いて音声を非同期に読み込み、実際の長さが4秒以内の候補を抽出して選びます。通常音声テーブルは非言語の字幕がある候補だけを使います。性格別の固定ファイル一覧は持たず、連続で同じ音声を選びません。付着したキャラの通常音声だけを再生開始時に止め、注射器の会話と既に再生中の反応は保護します。準備中の反応は溜めず、H終了・性格変更後の古いロード結果は破棄します。
- 接触時には保持中のHシーンからキャラ一覧と音声コントローラを再取得し、H開始後に初期化された情報を反映します。音声コントローラの候補が未準備なら、ゲーム標準の性格別テーブルを直接読みます。常時探索は追加しません。
- ロウソクの反応から絶頂音声（h_on系の013）を除外します。セクシーの確認済み候補は短い2本だけです。他の機能の絶頂音声は変更しません。
- 蝋は肌だけに付着します。服・髪・物・Colliderは滴を止めず、その下の顔・体の肌へ届きます。肌に届かなければ滴は消滅します。
- 付着対象は呼び出し時に取得し、後から追加・交換した物は「付着対象を再取得」で更新します。
- 本体の外側にある不可視の影用メッシュ（layer 11のo_shadowcaster／o_shadowcaster_cm）は、MagicPaint共通の可視判定で接触対象から除外します。
- スキンの変形・移動には元の描画メッシュのUVとして追従します。読取不可のスキンはBakeMeshで接触面とUVを取得します。
- 飛行中128滴、付着512個が上限で、超えた分は古いものから破棄します。
- ユーザー承認済みの例外として、表示・点火中だけ傾きと滴下を毎フレーム処理し、VRの手移動通知は購読しません。
- 消火で滴下と飛行中の滴を停止しますが、保持は続けます。フォーカス喪失・削除・無効化・H終了で保持と操作権も解放します。
- モデルは約20cm×直径1.8cmのコード生成メッシュ、炎は粒子、灯りは暖色のPoint Lightです。
- 専用の粒子シェーダーが省略された環境では既存のスプライト材質等を使い、炎の材質不足だけで本体を破棄しません。
- VRの入力フォーカスとデスクトップのフォーカスは独立して扱い、HMDで操作できる間はデスクトップの非フォーカスだけで呼び出しを拒否しません。
- 燃焼による短縮、蝋の保存、別シーンへの持ち越しは行いません。

## 検証と配置

`tools/Build-Candle.ps1 -Tests`で製品ビルドとロウソク・VR操作権・音声Bridge・PlaybackBarホストの境界テストを実行します。

`tools/Deploy-Candle.ps1`はゲーム停止確認、正規成果物の照合、既存DLLの退避、配置とハッシュ検証を行います。

境界テストはUnity・VRの代替実行環境であり、炎・付着・音声・実機操作の確認にはなりません。
