# ドールモードのプリセット

プレイバックバーの拡張「ドールモード」タブで選択・設定する。タブの並びは鎖、注射器、ドールモード。

初回に配置済みconfig.jsonの値をそのまま「基本」へ保存する。基本は上書き・削除せず、変更を残す場合は名前を付けて保存する。自作プリセットは選択、上書き、削除ができ、presets.jsonへ保存する。読込みに失敗した既存ファイルは上書きしない。

目・眉・口の番号、目と口の開き、頬、涙、汗、重ね画像、W/Sの動き、切替時間、対象・他の表情制御を設定できる。編集値は有効な入力へ変わった時にその場で反映し、ファイルへの保存は「現在の設定を保存」かプリセット保存で行う。プリセットを選ぶとその値を適用し、モードのON/OFFと診断ログ設定は変えない。

スライダー・文字入力は共通入力APIへ接続済みの総合UI／PlaybackBarホスト内に描画する。独立した設定窓やエディターは使用しない。画面操作と描画の実機確認はユーザーが行う。

設定欄は幅560px、番号入力欄は70px。涙・液体・MOD効果の段階は「なし／1／2…」のラジオボタンで選ぶ。SkinEffectsの涙・よだれ・唾液・汗・鼻の液体と、目パターンから独立した螺旋瞳の重ね表示もプリセットに保存できる。これらの追加効果はモード開始・設定変更時だけ操作し、解除時は変更前へ戻す。別の処理が後から変更したMOD効果は上書きしない。

「ハート瞳の上に螺旋を重ねる」で両方を同時に表示できる。螺旋の横・縦位置は各-0.5～+0.5、縦は正で上方向。位置は変更時に反映し、プリセットへ保存できる。「螺旋の位置を中央に戻す」で両方0に戻す。

「SkinEffectsの効果を指定する」内の「bukkake（MOD 0～3）」は導入済みKKS_SkinEffectsのBukkakeLevelへ反映し、プリセットに保存・復元する。0は消去、1～3はMODの段階。旧プリセットの未指定値は0。適用はモード開始・設定適用時だけで、解除時は外部で変更されていない値を元に戻す。
