# AI少女・本編島をAllPoseRoomで使う

AllPoseRoomのフリーHを開き、既存の「マップ」タブから「AI少女・本編島」を選ぶ。

キャラとH処理はAllPoseRoomに残し、島全体を追加シーンとして読み込む。

自由カメラで場所を探し、「今見ている場面をキャラ位置へ移動」で島をキャラに合わせ、必要なら既存のX/Y/Z位置・回転・回転中心を調整する。

島の配置設定は`11.RoomOverlayPosition.ai_shoujo_main`に保存し、読み込み直すと復元する。

AI少女とKKSは元データの単位が10倍違うため、島は標準で1/10へ変換し、地形・植生・当たり判定も合わせる。

Lux Waterの海面は複製した材質でXYZの波変位をMapScale倍、4つの波の空間周波数を1/MapScale倍へ補正し、時間パラメーターを保持し、島の解放時に複製材質を破棄する。

## カメラ

- マウスは既存のHカメラ操作を使い、矢印キーで前後左右、PageUp/PageDownで上下へ移動する。
- 島の表示中だけ位置・距離・回転の制限を解除し、終了時に元の値へ戻す。
- 移動速度は初期値1倍（通常速度）・範囲1～100倍で、旧初期値10倍の保存設定は一度だけ1倍へ移行する。
- 遠方描画は初期値500m・範囲50～10000mで、大きいほど遠景を描いて負荷が増える。
- 速度と描画距離は「マップ」タブで変更・保存でき、「島設定を再読込」で設定ファイルから読み直せる。
- 歩行操作や島全域への新しいHポイント配置は追加しない。

## 描画負荷と空

カメラから対象の外接球表面まで10m以上で簡易LODへ切り替え、9m未満で詳細へ戻す。9～10mは直前のLODを保持して境界の往復による切替を抑える。

既存LODGroupは最後のテクスチャ付きモデルを使用し、白い無地の板や空LODは選ばない。末尾が白い板なら一段手前の表示できるモデルを使う。LODのない静的メッシュはDLL内の事前生成済み簡易メッシュを共有し、未生成・小規模・識別が曖昧なメッシュは元の形状を保って影を簡略化する。

簡易メッシュは元のサブメッシュ・UV・色・法線・接線を保持する頂点クラスタリングでオフライン生成し、ゲーム中に形状を計算しない。材質・テクスチャ・専用シェーダーは元のまま保持し、一般的なDiffuseへの置き換えで葉の透過や板ポリゴンを白くしない。スキニング形状は保持する。

海・川はシェーダー名（Lux Water・AQUAS等）と波のプロパティで検出し、メッシュ・材質・影・LOD操作すべての変更対象から除外する。水面を含むLODGroupは全体を除外し、単体メッシュ処理への再混入も防ぐ。オフラインの簡易メッシュ生成にも水面を含めない。

画面外・壁裏・従来の小物/建物距離による強制非表示とレイ検査は撤去し、距離帯の変更通知だけでLODを変更する。毎フレームの探索・物理レイ・走査コルーチンはない。

地形の木は10mから標準ビルボード、地形材質は10mからベースマップを使う。木の最終描画距離は標準200m、草は最大30m、カメラの遠方描画は標準500m、動的な影は標準25m。

前版の初期遠方描画200mは500mへ、地形の木40mは200mへ一度だけ移行する。独自LODによる島のメッシュ非表示は行わないが、カメラのfar clipと地形の植生描画距離は有効。

これらの変更はAllPoseRoom用MainGameBlankMapAddだけに適用し、AI少女モードと共有するMapEnvironmentRuntimeや元の島データは変更しない。終了時に元のメッシュ・材質・影・自動LODを復元し、生成物を破棄する。

水面反射は標準オフの空色表示とし、オンでは256画素・毎秒最大5回・植生の描画距離まで島を描き直す。

独自の簡易空・空の球体・生成した昼用照明は追加せず、読み込み前のKKSの空・環境光・霧・環境反射を使う。

炎・煙・水しぶきなどの粒子は親階層の縮尺を使い、読み込み時の巨大な粒子を消去してから再生状態を復元し、画面外ではUnityの自動処理省略を使う。

19個の旧式発光表現（Halo）は追加データ側のサイズを元の1/10へ直す。

実寸補正は標準0.1倍（0.01～1倍）で次回読み込み時に適用し、旧版の初期遠方距離3000mまたは200mは500mへ、反射512画素は256画素へ移行する。

## 読み込み用データ

配置先はプラグインフォルダー内の`Assets/AiShoujoMain`で、`manifest.json`と本体1バンドル・依存6バンドルを置く。

別の場所を使う場合は`com.kks.maingameblankmapadd.cfg`の`13.AiIsland.DataDirectory`に加工済みデータのフォルダーを指定する。

元のAI少女のゲームフォルダーや、未加工の抽出フォルダーを指定してはいけない。

本編島のモデル・画像・地形・植生・LOD・当たり判定の元データを保ち、AI少女専用のコンポーネントと未使用のスクリプト型情報を除去する。

地形は元のCTSシェーダーを追加して14層の材質設定と画像配列・4枚の混合画像を焼き込み、水面には必要な平面反射処理を追加する。

空と環境光はKKS側のものを保持し、既存の「空・環境光」ページでも変更できる。

## 中止・解除・診断

読み込み中は段階を表示して「島の読み込みを中止」を使え、実行中のUnity読み込み処理が終わってから元の部屋へ戻す。

「元の部屋に戻す」、別マップへの切替、退室、無効化で島を解放し、カメラと環境を復元する。

読み込み・失敗・解放の記録だけをプラグインフォルダーの`AiIsland.log`へ保存し、毎フレームのログ出力は行わない。

描画診断は同じフォルダーの`AiIsland.Performance.log`へ記録し、初回は島の表示から60秒だけ記録した後に設定もオフへ保存し、マップタブの「描画診断ログを記録」で即時停止・再開できる。

診断時間は10～300秒、集計間隔は1～30秒（標準2秒）で、ファイルは4MiBで停止し、次の開始時に前回分1世代を残して入れ替える。

記録内容は平均・最大フレーム時間、FPS、フォーカス、距離・壁裏の省略数、視野内候補数、遮蔽物数、レイ数、判定CPU時間、実際に描画されたカメラ名と回数、Unity内部CPUマーカー、取得できる場合のCPU/GPUフレーム時間で、候補数を実際のドローコール数とは扱わず、取得できない時間はunavailableと記録する。

診断オフ・切替・退室・無効化でファイルを閉じ、カメラ通知とこの診断が有効化した計測だけを解除し、「読み込み・失敗ログも記録」をオフにすると通常ログの書き込みも停止する。

ファイル不足・サイズ不一致・SHA-256不一致・CTSシェーダー非対応の場合は理由を表示して、途中まで読み込んだ島を解放する。

manifestはUnityのJsonUtilityを使わず、明示したJSON項目名で読み取る。不一致時は対象項目と実際の値を表示する。

## オフライン検証と実機確認

`scripts/prepare_ai_shoujo_map.py`で加工と再読み込み検証を行い、`scripts/verify_ai_island_native.py`で元のモデル・画像・地形等のバイト一致と材質参照を検証する。

カメラの制限解除・速度・復元は`MainGameBlankMapAdd.AiIsland.Tests`、縮尺・粒子・KKSの空の保持・描画省略は`MainGameBlankMapAdd.AiIsland.Rendering.Tests`、既存UIの入力とレイアウトは`MainGameBlankMapAdd.EmbeddedUi.Tests`で確認する。

オフライン検証はゲーム内での読み込み成功を証明せず、表示・木や水の描画・自由カメラ・配置変更・体位変更・保存・別マップ切替・退室と再入室はユーザーが実機で確認する。
