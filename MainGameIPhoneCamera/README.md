# MainGameIPhoneCamera

本編フリーH・公式VRで、導入済みearthship iPhone Xの画面にカメラアプリを表示し、縦横のPNGとゲーム音声付きMP4を保存するプラグイン。

## 端末の画面と操作

- 閲覧中の説明・ファイル名・ボタンは別の段に配置し、横画面の操作ボタンは1列で表示する。UIは操作のたびに待機時間をリセットし、スティック・トリガーの操作中は表示を維持して、操作終了から3秒後に消す。

- ロック・ホーム・一覧・写真／動画表示・壁紙編集・設定案内・追加アプリ・写真／ビデオ撮影の全画面で縦横に対応し、向きの変化は0.32秒の共通回転・配置アニメーションで切り替える。横持ちのホームと一覧は5列で表示し、録画中もUIは端末の向きに追従するが保存方向は録画開始時のまま維持する。

- 呼び出した端末はロック画面で始まり、右Aでメニュー、保持側のトリガーでカメラを開き、ロック画面からの最初のトリガーでは撮影しない。
- メニューは「写真・カメラ・設定」の3アイコンを持ち、右スティックを十字キーとして選び、右Aで決定し、アプリ内の右Bでメニューへ戻る。
- メニュー・ロック・各アプリにPCの実時刻を24時間表示し、ロック画面には日付も表示し、時計は表示中だけ次の分の期限で更新する。
- 手を離して60秒でロックし、さらに30秒で画面を消し、保持中と録画・動画再生中は自動ロックを保留し、録画・再生終了後に置いてあれば60秒を数え直す。
- 60秒未満の掴み直しは元の画面を保ち、ロック・消灯後に掴むとロック画面を表示し、放置判定は離す・掴む・再生状態の変更から一度だけ期限を予約する。
- 写真アプリはiPhone撮影分と設定で追加したフォルダー直下の画像・動画を新しい順に表示し、右スティックとAで選び、表示ページに必要なサムネイルだけを非同期生成する。
- 写真・動画の閲覧はUIの余白を取らず全画面へ縦横比を保って全体を収め、UIは最後の操作から3秒で消え、非表示中のAは再表示だけを行う。
- 閲覧中はUIの表示・非表示に関係なく右スティック上下で1～20倍にズームし、保持側または右手のトリガー＋右スティックで画像の端まで上下左右に移動し、端末解放・画面遷移で動きを停止し、UI表示中だけ左右で操作ボタンを選ぶ。
- 端末の向きは画面が有効な間だけ1秒ごとに判定し、画像・動画・一覧・撮影UIを縦横へ切り替え、非表示・H終了時に判定を停止する。描画時の毎フレーム判定は行わない。
- 写真・動画を開いた後は、画面の「一覧へ・前へ・次へ・再生／一時停止・±10秒・待受に設定」を右スティックで選んでAで実行し、Bは閲覧中なら一覧へ、一覧ならメニューへ戻る。
- 動画はUnityのVideoPlayerで再生し、MKVや標準再生に失敗したファイルはFFmpegでH.264/AACの互換コピーを非同期作成して再試行し、元動画を変更せず、退出時は準備・変換・再生を解除する。
- 写真の「メニュー待受」「ロック待受」からそれぞれ別の画像を作れ、位置・倍率を右スティックで調整してAで調整を終え、「保存」で縦長PNGを作り、未保存のBは編集を破棄する。
- 切り抜き位置と倍率はiPhoneタブのスライダー＋数値入力でも調整でき、元画像を変更せず、作成した画像は `UserData/IPhoneCamera/Wallpapers` に保存する。
- 設定アプリは実際のF1コンフィグマネージャーを開き、検索を `MainGameIPhoneCamera` にしてiPhoneの項目を展開し、終了時は独立したユーザー操作を上書きせず以前の表示・検索を戻す。
- 録画中のBは録画を停止して保存しながらメニューへ戻り、動画の閲覧を終了すると再生と端末の3D音声を停止する。
- 右A/Bは専用SteamVRアクションセットで識別し、既存ゲームのA/B・スティック押し込みの割り当てを変更せず、保持中だけ有効にし、左手で保持する場合も右手の操作権を確保・解放する。
- 初期の3アプリ以外は `IPhoneAppApi.Register(IPhoneApp)` で追加でき、アイコン一覧は登録式でページを増やせ、追加アプリの開始・終了・入力も有効なHと保持中の操作に制限する。

- H開始時は非表示にし、総合UI／PlaybackBarの「iPhoneカメラ」タブの表示／非表示ボタンで切り替え、表示するたびに現在の視点の45cm前へ配置する。
- プレイバックバーの「iPhone」は左クリックで現在の視点の45cm前への呼び出しと共通ギズモ表示を交互に実行し、右クリックで削除し、削除後は呼び出しから再開する。
- ギズモはiPhone本体を直接動かし、呼び戻し・VR保持開始・フォーカス喪失・非表示・H終了で非表示と入力解除を行い、表示失敗時は交互操作を進めず再試行できる。
- 非表示時は保持を解除して本体・カメラ・映像用リソースを破棄し、以前置いた位置へは戻さず、旧SpawnOnStart設定は使用しない。
- VRでは本体の14cm以内でグリップを押している間保持し、写真モードでは同じ手のトリガーで1枚撮影し、ビデオモードではトリガーで録画開始・停止し、グリップを離すとその場へ置く。
- カメラアプリでは右手のパッド／スティック左右で写真／ビデオを選び、上下に倒している間は連続してズームし、中央へ戻すとその倍率で止まり、斜め入力は強い軸だけを採用する。
- ズームは0.1～20倍で背面カメラの画角へ反映し、録画中も変更でき、端末画面の倍率表示とタブのスライダー・数値欄を同期する。
- 実画面にモード選択のスライド、録画ボタンの丸から停止用四角への変形、録画表示のフェードと赤印の脈動、撮影フラッシュ、保存通知、サムネイルの拡大アニメーションを表示する。
- 画面UIは実メッシュの丸い外周とノッチでクリップし、保存映像には操作UIや端末自身を入れず、録画中・保存中はモード切り替えと二重開始を拒否する。
- 写真は `F:\kks\UserData\cap\iPhone_日時_識別子.png` に保存し、シャッター時の縦横と上下を画素へ反映し、既定は縦886×1920・横1920×886で保存する。
- 動画は同じフォルダーの `iPhone_日時_識別子.mp4` に保存し、既定は縦498×1080・横1080×498・30fpsのH.264映像とAAC音声で、開始時の縦横・回転補正を停止まで固定し、Video設定のHeightは長辺として次回開始時に使う。
- FFmpegの既定パスは導入済みの `J:\system_tools\ffmpeg\bin\ffmpeg.exe` とし、エンコードとファイル出力は上限付きキューのワーカーで行い、処理が追いつかない場合は失敗理由を表示して停止する。
- 音声は録画開始時に有効な既存AudioListenerへ専用フィルターを付けて取得し、出力音声を変更せず、マイクやデスクトップ全体の音声は収録せず、音声が取得できない場合は保存失敗として途中データを残す。
- 録画停止・非表示・H終了・無効化・フォーカス喪失・音声出力変更で収録を止め、開始済みの保存は完了させ、破棄前や前のHの完了通知を新しい端末へ反映しない。
- 写真保存・録画開始・動画保存完了時に保持側へ短い振動を出し、成功／失敗と保存名をタブへ表示する。
- ConfigManagerのPhotoHeight・VerticalFov・GrabRadius・LensPosition・LensRotationで解像度・画角・保持距離・背面カメラの位置と角度を設定する。
- 旧MainGamePhonePreview・スタジオ用プラグインへの参照、Studioシーンの生成、原始形状によるiPhone代用品は使用しない。
- canon_gateの許可をH開始時に受け、既存のAllPoseRoom／個別例外設定に従い、通常マップの例外設定を自動変更しない。
- 終了・無効化・破棄で入力購読と生成物を解除し、フォーカス喪失・追跡喪失・コントローラー切断で保持を解除する。
- 手への追従はTransform親子付け、入力はSteamVRの左右別押下／解放・軸変化イベント、画面遷移はUnityのAnimationClip、収録は録画中だけのカメラ描画・音声コールバックで処理し、向きだけはユーザー指定の1秒ごとの判定を使う。Update・常駐コルーチンは追加しない。
- カメラ描画イベントでは自分のiPhoneだけを非表示にし、画面の再帰映像を防ぎ、全体のレイヤーやゲームのカメラ設定は変更しない。
- 操作UIはMainGameUnifiedUiに登録し、ホストのMainGameUiInputCaptureによる入力保護を使う。
- 必須依存はcanon_gate 2.4.0、MainGameUnifiedUi、MainGameUiInputCapture、MainGameTransformGizmo、Sideloader、導入済みearthship iPhone X zipmodとVRGIN_OpenXR実行環境。

## 検証

製品DLLを実KKS DLL参照でReleaseビルドし、境界テストで左右入力・保持・他方入力拒否・解放・失効・追跡喪失・購読解除・縦長サイズと導入済み実メッシュの画面生成を確認する。

境界テストはUnity／SteamVRの実行境界を代替し、Movieテストは合成画像・音声を製品ワーカーと実FFmpegへ通してMP4の形式・向き・音声・時間・失敗処理を確認し、実機の画面アニメーション・VR操作・ゲーム音声の取得・撮影結果はユーザーが確認する。

## ビルドと配置

`dotnet build MainGameIPhoneCamera\MainGameIPhoneCamera.csproj -c Release` で専用binに生成し、配置時は `scripts\Deploy-IPhoneCamera.ps1` がゲーム終了・重複DLL・サイズ・更新日時・SHA-256を確認する。

`Deploy-IPhoneCamera.ps1` はiPhone専用A/B入力も `Install-IPhoneInput.ps1` で配置し、既存SteamVRアクションと既存ゲームのバインドが変わっていないことを確認し、元ファイルをreportsへ退避する。
