# MainGameMagicPaint

画像の外観案を基に、前端が色付きの平たいペン先・後端が白い消しゴムのマジックと、金属肩部・色付きノズル・黒いグリップのスプレーを立体生成します。

## 呼び出し

- 対象のフリーHで、PlaybackBarのiPhone右隣にある「マジック」を押します。
- 操作ボタンが一行に収まらないときは折り返し、iPhoneとマジックは同じ行で隣同士に保ち、増えた行の分だけ下段一覧とバーの高さも調整します。
- 左クリックは視点前へ呼び出しとギズモ表示を交互に実行し、右クリックはアイテムだけを削除します。
- 総合UIの「マジック・スプレー」タブからも呼び出し・設定・保存・読込ができます。
- canon_gateの許可範囲は既存設定に従い、通常マップの許可設定は自動変更しません。

## VR

- 本体から12cm以内でグリップを押すと、その手で保持します。
- スティック押し込み中に道具選択を表示し、左がマジック・右がスプレーで、押し込みを離して決定します。
- 中央で離せばキャンセルし、選択UI中は通常のスティック操作を止め、閉じた後も中央へ戻るまでUNDOなどを誤発動させません。
- Aで本体右側の調整項目を開閉します。表示中は上下で項目を選び、左右で数値とゲージを調整します。色は左右で切り替えます。
- 透明度は右で増加して透明になり、ゲージも伸びます。左で減少して不透明になります。
- 調整項目を閉じている時の左右はUNDO／REDO、Bは最後に狙った選択キャラの顔・体の落書きを全削除し、UNDOで復元できます。
- マジックは先端または後端を肌へ近づけて自動接地し、トリガーで描画または消去します。
- スプレーは30cm以内で噴射でき、肌へ投影した範囲の輪郭と中心点を表示し、色一覧の「消去」で既存の落書きを薄くして消します。
- 握っている間だけ肌の判定・ガイド・調整表示を更新し、手の移動通知の購読は追加しません。
- Touchは保持している手のA/B相当、左手はX/Yに対応し、Indexはその手のA/Bに対応します。
- 新しい入力設定は次回ゲーム起動から読み込まれ、既存iPhone・legacyの入力設定は保存します。

## 通常版と保存

- タブで対象キャラと道具を選び、「マウスで描く」または「マウス消しゴム」を押し、左ドラッグで編集します。
- Ctrl+Z／Ctrl+YでUNDO／REDO、Deleteで全削除、Escで描画を終えてタブへ戻ります。
- マウスのスプレーはカーソルの肌の10cm手前に仮想ノズルを置いて吹き付けます。
- 保存先は `F:\kks\UserData\MagicPaint\保存名\` で、顔1024px・体2048pxのPNGと形式情報を保存します。
- 同名保存は上書きせず別名を要求し、読込は選択キャラへ適用し、読込前にもUNDOで戻れます。
- 元の肌・既存タトゥー・キャラカードは変更せず、H終了で未保存の落書きを破棄します。
- 履歴は変更した32pxタイルだけを保存し、32操作または約64MiBを目安に古い操作を削除しますが、最後の全削除は必ず一操作として残します。

## 実装上の初期値

- 初期色は外観案と同じ青で、黒・白・赤・オレンジ・黄・緑・水色・青・紫・ピンクと消去スプレーを用意します。
- マジック線幅は3mmで0.5～30mm、消しゴムは10mmで2～50mm、接地開始20mm・解除と最大補正30mmです。
- スプレーは10cm先で直径50mm、粒1mm、透明度0%、600粒／秒、縁のぼかし70%、ばらつき50%です。
- 設定値はタブのスライダーと数値欄で変更でき、ドラッグ中のディスク保存を避け、操作終了時に設定を保存します。
- 診断ログは `Diagnostics / Enabled` が既定OFFで、OFFでは診断出力や診断用監視を行いません。

## 今回の修正と実機結果

- ユーザー確認：体ではマジック・スプレーとも描画可能。顔では接地表示も噴射ガイドも出ていない。今回の修正版で顔が直ったかは未確認。
- マジック／後端消しゴムは保持・肌への接地・トリガーの3条件、スプレーは保持・その時点の有効な肌ガイド・トリガーの3条件で描画／消去します。解放時に止まり、再保持だけでは再開しません。
- 接地開始20mm・解除と補正上限30mm。前端・後端の接地状態を分離し、再確認位置が3mmずれると拒否していた条件を、衣服などの遮蔽判定から分離しました。
- 関係する描画部品の候補を一サンプル内で共有し、座標変換の行列をまとめて取得。ガイドの一時配列を再利用し、変更のない画像は更新しません。
- 読み取り不可の元スキンメッシュにはBakeMesh後のデータを使用します。非表示の描画部品は遮蔽物にせず、顔・体のネイティブ参照が通常の階層外にあっても取得します。これらが今回の顔の原因だったとは未確定です。

## 描き込み先のPNGを確認する手順

1. 総合UIの「マジック・スプレー」タブで「次の一筆を検査」を押します。検査の開始ボタンで診断を一時的に有効にします。追加のチェック操作は不要です。
2. 顔を狙って保持し、トリガーを押して離します。グリップを離しても検査が終了します。接地できず描けなかった場合も取得します。
3. 有効な入力が5秒来なければ未入力として保存します。入力が来ていれば解放まで待ちます。キャンセル・H終了・無効化では保存を止めます。
4. 保存先は `F:\kks\UserData\MagicPaint\Diagnostics\日時-ID\actor-1\` などです。保存結果とパスはタブに残ります。複数の女性に描いた場合はactor別に分かれます。

- `face-cpu-ink.png` / `body-cpu-ink.png` は実際の書き込み先、`*-gpu-ink.png` はGPUのインクです。
- `*-slot番号-original.png` / `*-composed.png` / `*-assigned.png` は元の肌・合成後・実際の割り当てです。検査のための再合成・再割り当ては行いません。
- 元画像が未作成ならPNGを代作せず、`state.txt` に未作成と記録します。顔の対象、メッシュの読取可否、直接の接触・射線判定、遮った部品も記録します。
- 検査は一回で停止し、開始前の診断設定へ戻します。OFFでタイマー・画像読み戻し・ファイル作成は行いません。通常描画中にはPNG保存しません。
- 保存された実PNGを確認するまでは原因特定・顔の修正完了とはしません。VR撮影とタブ内プレビューは追加していません。

## 接地・書込の詳細ログ

`Diagnostics / Enabled`（既定OFF）をONにすると、`F:\kks\UserData\MagicPaint\Diagnostics\magicpaint.log` に操作・状態変更時だけ出力します。今回の調査ではユーザー指示によりONで配置します。

- INPUT：保持手、トリガー受信／拒否、接地・ガイド・操作権。
- NIB_CONTACT / ERASER_CONTACT：接地成立、距離内に三角形なし。距離・開始／継続しきい値・接触点・法線。
- 遮蔽判定とOCCLUDER / PHYSICAL_OCCLUDERログは撤去済み。顔・体以外を収集しません。
- SPRAY_GATE：肌なし・距離外・有効ガイドの成立状況。
- GEOMETRY / MESH：トリガー操作時に、保持中のキャッシュだけで顔・体の実測最短距離、符号付き深さ、頂点範囲、座標変換方式の差を比較します。検査用にメッシュを再生成しません。
- STROKE_END：顔／体への実書込回数、非透明画素数、割当状態。RASTER_FACE / RASTER_BODY：向き・距離・退化三角形・UVでの拒否と実書込数。
- 接地が境界で頻繁に切り替わっても、各状態ログは一回の保持中に12回までで抑止します。操作と一筆の終了要約は残します。
- OFFではメッセージ生成・診断の幾何計算・ファイル作成を行わず、出力中のファイルも閉じます。タブの診断チェックで停止できます。

## 顔の移動・回転時の座標修正
ユーザー実機で顔が動くと座標が合わなくなるとの結果。保持中のLateUpdateは実行順未指定で、既存VMDの頭向き更新30000より先になる構造だった。32000へ移し、追加のループ・購読は導入しない。BakeMeshのワールド変換はRenderer.localToWorldMatrixを廃止し、現在Transformの位置・回転（スケール再適用なし）へ変更。Unity公式SkinAttachmentTargetの変換方式を参照。範囲粗判定は現在TransformのlocalBoundsも含めフレーム内再利用。前のストローク点は三角形の重心座標で保持して現在の変形済み肌へ移動させ、古いワールド位置との補間を撤去。他メッシュの探索・遮蔽は復活させない。169コア＋30実VR入力＝199試験成功。移動・回転後の接地・レイ・スケール・表情変形追従を製品用計算で確認。実機追従は配置後の確認待ち。
